# circus-it.eu design direction

## Purpose

Introduce Circus IT as the technical studio behind a growing collection of
independent WordPress websites. The page should make the work understandable
without turning an early-stage site into a premature portfolio.

## System

- Canvas: white (`#ffffff`)
- Text: near-black (`#111111`)
- Secondary text and rules: grey (`#666666`, `#d8d8d8`)
- Signal: cobalt (`#1f4fff`)
- Display and body: the operating-system sans-serif stack
- Utility text: the operating-system monospace stack

The signature is a thin cobalt vertical signal beside the opening statement.
It suggests a text cursor and an active process: precise, unfinished, and ready
for the next automated step. Everything else stays quiet.
